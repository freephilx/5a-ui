# 已有 3x-ui 接入

## 目标

通过 SSH 接入服务器已有的 3x-ui，与安装来源无关。沿用现有产品的状态读取、流量查看、节点二维码/复制/导出能力，扩展到多实例、多入站、多客户端。已有实例接入不创建 API token、不重置账号、不修改数据库、订阅或服务配置。

## 实现

1. 共享远端只读检查器发现 systemd/独立进程和 Docker 实例，识别数据库位置、服务状态和映射端口；读取 SQLite 的旧版内嵌客户端及新版独立客户端表，PostgreSQL 使用服务器已有的 psql 客户端。
2. 状态响应增加 instances / inbounds / clients；各层只返回展示所需字段，私钥、面板密码、API token、数据库凭据不离开服务器。常见协议生成可导出的客户端连接链接；无法可靠转换的配置显示原因。
3. 已有安装的部署请求直接返回接入结果，只有未发现服务时才开始新部署。保留本项目未完成安装的恢复流程。
4. Flutter 增加实例选择、入站列表及客户端状态/流量/链接。Dart 与 TypeScript 共用脚本、响应样例和一致性测试。
5. 用临时数据库、服务/容器发现模拟和界面测试验证；不连接生产服务器执行修改。明确展示无法读取、未映射端口、未知协议与返回数量上限，不能误报成未安装或空列表。

## 验证

- 没有 .managed 标记的已有安装也能读取；读取前后数据库和配置不变。
- 多实例、停止的服务、Docker 端口映射、独立客户端表、禁用/过期节点均可表示。
- 安装入口遇到已有实例不执行安装、改密码或创建新节点；错误不能降级为新安装。
- 自动测试覆盖客户端链接参数、敏感字段过滤、跨语言响应和窄屏界面。
