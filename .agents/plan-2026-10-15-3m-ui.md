# 3m-ui 接入与可选部署

- 用户要求：已有 3m-ui 与 3x-ui 一样可管理；默认部署 3x-ui 并创建节点，可改选 3m-ui。
- 基线：保留此前未提交的完整 3x-ui 管理实现；本轮不提交或推送。
- 上游：3m-ui 稳定版 v1.4.1，依据 Go 路由、DTO、配置与安装脚本审计；Mihomo 与 Xray 使用独立适配。

## 验收工作

1. 面板类型契约、原生 / Docker 多实例发现、只读状态；识别失败不覆盖安装。
2. JWT / TOTP / 首次改密；Listener、用户、配额到期、绑定和分享；配置、路由 / DNS、TLS / REALITY、日志、备份恢复、服务 / 版本与其余上游接口。
3. 默认 3x-ui 与可选 3m-ui 的后台部署、节点创建、幂等恢复；面板首次启动即回环监听。
4. Dart / TypeScript / Python 一致性及 Flutter 交互测试；使用项目外材料在获授权第一台 Oracle 的隔离环境验证；不得更改生产配置或在项目保存真实信息。
5. 清理测试资源、扫描敏感信息、记录实际覆盖和未验证限制。
