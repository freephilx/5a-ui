# 可选保存服务器

- 参考 AmneziaVPN dev `705a373d510102fbce3c75149d005ca533717b10` 的 SecureServersRepository、SecureQSettings：服务器列表、默认项、启动恢复与本机删除；仅参考流程，不复制 GPL 源码。上游 Linux 桌面当前关闭配置加密，不能据此宣称其所有平台都加密。
- 5a-ui 通过用户主动点击保存，在仅连接信息与包含当前认证凭据之间选择；启动恢复最后选择的服务器表单，远端状态仍在用户点击连接后读取。
- 使用 Flutter secure storage，平台原生密钥存储/加密存储；Web 使用 WebCrypto，明确浏览器和站点的访问边界。无明文降级，不保存验证码、后端证明、面板会话、节点/日志或真实测试服务器材料。
- 提供切换、新增、更新、删除记录与清除会话；存储错误和损坏不得静默重置或覆盖。保留已核验 SSH 指纹。测试使用内存存储和合成配置，真实持久化回归只用合成资料并在完成后清理。
- 验证：模型/异步存储/错误恢复/凭据过滤/重启恢复交互测试、Web 与 macOS 构建及实际合成持久化，记录其他平台边界。
