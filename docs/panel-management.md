# 连接后管理能力与验收

本文记录 3x-ui / Xray；3m-ui / Mihomo 的独立接口、功能矩阵与部署行为见 [3m-ui-management.md](3m-ui-management.md)。两类面板共用 SSH、实例选择、编辑确认与错误处理流程。

接口依据：3x-ui v3.6.0 `c377dca` 与 v3.10.0 `74c3cc3` 的 controller、service、数据库模型和 OpenAPI。`contracts/panel-operations.json` 包含 180 项操作，3.6 基线包含 161 项。连接时读取实际 OpenAPI，界面只展示交集；接口数量不代表逐项验收完成。

管理入口在每个实例卡片中。SSH 确定服务器和实例，面板认证确定 API 权限。已有账号、节点、订阅不会在接入时被重置。Docker 请求在选中容器网络内执行，不要求公开面板端口。独立服务启停使用已发现的准确 systemd 单元或 Docker ID。

| 范围 | 操作方式与实现 | 本轮真实验收 |
| --- | --- | --- |
| 多实例与认证 | 保留原有只读发现，账号/密码/二步验证码、API token、内存 Cookie/CSRF 会话 | 两版 Docker、SQLite、显式入口的 PostgreSQL；登录、无效 token、权限拒绝 |
| 入站 | 列表、增改删、启停；常用字段和完整 JSON，保留未知字段 | 两版完整增改删启停、保存回读；PostgreSQL 增改删 |
| 客户端 | 增改删、启停、配额与期限、关联入站、流量与分组 | 两版配额/期限/启停/分享、流量修改与重置、分组增删和成员管理 |
| 协议/传输 | 完整 settings、streamSettings、sniffing、allocate 编辑 | 两版 REALITY 和 TLS/WebSocket 保存回读；没有对每种协议执行真实数据面握手 |
| 分享/订阅 | 面板生成链接，二维码、复制和导出 | 两版链接与订阅接口；Host 来自已连接地址或面板绑定域名，避免生成回环地址链接 |
| 出站/路由/DNS | 完整 Xray 模板编辑、上游校验、保存回读 | 两版真实添加出站、域名规则与 DNS，并恢复测试前模板 |
| 面板设置 | 完整设置编辑；用户、token、二步验证和通知的高级接口 | 两版设置修改回读；权限/token 回归见 verification；没有向外部邮箱或消息服务发送通知 |
| 日志 | 面板/Xray/AmneziaWG 日志参数化查询，响应上限保护 | 两版面板日志；未安装的组件由面板报告不可用 |
| 备份恢复 | 二进制下载、文件导入、精确重启、重新认证；最大 2 MiB | 两版 SQLite 和 PostgreSQL 18 备份→修改→恢复→重新登录→回读；缺少 PostgreSQL 工具时错误提示通过 |
| 实例服务 | 确认后启动、停止、重启所选服务；重新读取状态 | 两版 Docker、隔离标准 systemd 生命周期及 Xray 停止/重启；自定义 systemd 目标使用自动测试验证 |
| Xray 版本 | 面板发布列表选择、版本切换、轮询当前版本 | 隔离实例实际切换与切回；兼容状态值不带 v、发布标签带 v 的差异 |
| 面板版本 | 上游更新、更新渠道；界面按本次 runId 查询进度，成功后重新连接核对版本 | 隔离标准 systemd 从 3.6.0 升级到 3.10.2，原测试账号与路径仍可接入；Docker/自定义服务/共享程序目录有保护限制 |
| 其他原面板功能 | Hosts、远程节点、分组、订阅平衡、出站订阅等高级接口；编辑参数/JSON 后确认，读取响应 | 两版 Hosts/节点/出站订阅增改查删、节点探测、订阅刷新解析；新版订阅平衡权重和启停回读；第三方联动与所有版本组合未全面验收 |

高级操作直接调用被允许的真实 API，不提供任意命令或任意 URL 请求。上游 OpenAPI 未描述的部分请求体由已审阅 controller 的字段补齐（`tool/panel_schema_overrides.py`）；复杂对象可先读取，再携带完整配置编辑。高级接口保留技术参数，不等同于原面板全部专用表单。

## 数据一致性与失败处理

- 常用入站、客户端、面板设置、Xray 编辑带读取摘要；保存前回读检测其他会话的配置修改。流量计数不参与摘要。上游没有原子 CAS，检测与写入之间仍存在短暂竞争窗口；高级批量接口不提供原子多步事务。
- 写操作失败或超时不自动重试；先回读再决定。权限过期可重新认证。有限权限 token 无权获取 OpenAPI 时仅开放已验证的运行状态，完整配置管理需要已有管理账号或 admin token。
- SQLite 读取连接在调用面板前显式关闭，避免旧 WAL 持有导致恢复被旧内容覆盖。恢复前验证实例可被准确重启；旧版必须明确确认全量恢复，不能声称支持保留主机设置。
- 响应不显示原始数据库/HTTP 错误中的配置或凭据。PostgreSQL 缺少 pg_dump/pg_restore 时给出安装匹配客户端的提示。
- 订阅平衡的 inboundIds 按上游要求编码为重复表单字段，权重保留 JSON 对象；不能对所有表单数组使用同一种编码。
- 修改面板账号、访问路径、监听地址等可能使当前会话失效；按修改后的现有认证重新接入。备份可能包含账号、密钥和节点配置，导出文件需要妥善保存。

## 明确限制

- 低于 3.6.0 的版本暂仅支持只读发现；3.6–3.10 之间及之后的所有发行版没有逐一实测。接口缺失和不兼容返回明确错误。
- 面板自升级脚本固定操作 `x-ui.service`。Docker 应通过原有容器编排更新镜像；自定义单元或共享程序目录不允许从此入口运行该更新器。多个原生实例共享 Xray 程序时不允许独立切换它的版本。没有服务管理器的独立进程不能安全启停或自动重启恢复。
- PostgreSQL 的自动只读发现依赖宿主机 psql 与可访问 DSN；管理 API 可使用手动指定的本机入口。备份/恢复依赖面板环境内匹配版本的 PostgreSQL 客户端，应用不会擅自安装系统包。
- 自动发现不覆盖所有容器运行时和非常规布局。分享 URL 不自动修改用户的 Hosts/订阅配置；Docker 的外部端口映射和域名应在原有分享设置中配置正确。
- 未完成 Android/iOS/Windows/Linux 本轮设备交互验收，未部署新版本到云平台。外部通知、ACME/远程证书、全部远程节点拓扑、所有协议握手和所有高级操作组合仍需对应环境验收，不能据此宣称与原面板完全等价。

重建接口目录：`python3 tool/import_panel_api.py --spec <v3.10-openapi.json> --baseline <v3.6-openapi.json>`，随后运行 `fvm dart run tool/generate.dart`。样例必须为合成数据，不保存真实测试服务器资料。
